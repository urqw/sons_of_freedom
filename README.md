# Sons of Freedom, or The Last Flight of Egor Stanenko

Text-based game "Sons of Freedom, or The Last Flight of Egor Stanenko" (Russian: "«Сыны Свободы» или последний полёт Егора Станенко") by Ataman Platov (Russian: Атаман Платов).

The game is in Russian, developed for AkURQ and URQ_DOS, and adapted for [UrqW](https://github.com/urqw/UrqW) text-based game engine.

This repository contains the source code and other resources of the game. The game is available for launch in the [UrqW engine online catalog](https://urqw.github.io/UrqW/?id=sons_of_freedom).

The game was first published on July 3, 2008.

Interactive fiction identifier (IFID) of the game which is its MD5 hash: 7C1085AA947C555BA595AB959204A8A8

## Description

Недалёкое будущее, в Австралии появляется организация, называющая себя «Сыны Свободы», и быстро берущая под контроль власть в Австралии, а потом и в Китае. Когда всплывает тёмный секрет «Сынов Свободы», уничтожить их, не развязав войну, уже невозможно. Начинается третья мировая война, в которой медленно, но верно, побеждают «Сыны Свободы» или «Другие», как называют их в России и Европе.
Здесь и начинается история Егора Станенко, боевого лётчика-истребителя, попавшего в опасную и неоднозначную ситуацию и пытающегося спасти свою жизнь.
